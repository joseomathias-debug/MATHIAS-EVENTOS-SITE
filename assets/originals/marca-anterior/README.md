# Logo oficial da Mathias Eventos

Substitua este arquivo pelo logo oficial: `logo-mathias.svg`.

Depois da inclusão, altere `available` para `true` em `app/brand.ts`. Se o logo oficial existir apenas em PNG transparente, atualize também o caminho `src` no mesmo arquivo.

Não há um logo fictício nesta pasta. Enquanto o arquivo oficial não é enviado, o site usa apenas um wordmark tipográfico temporário.
